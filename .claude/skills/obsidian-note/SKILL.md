# Obsidian Note

UE5 학습/작업 내용을 옵시디언 볼트에 저장하는 마크다운 노트로 변환한다.

## 볼트 경로

`C:\Users\dygks\Documents\Obsidian Vault\KrakenVoyage-Notes`

- 개념 노트: `UE5/개념/{개념명}.md`
- 함정/트러블슈팅: `UE5/함정/{함정명}.md`
- Day별 정리: `UE5/Day별/Day{N}.md`

노트 유형이 애매하면 사용자에게 묻지 말고 내용상 가장 맞는 폴더에 넣는다 (개념 설명이면 개념/, 삽질·에러·오해였던 것이면 함정/, 하루 작업 요약이면 Day별/).

## 코드 예시 원칙

코드 예시는 반드시 이 프로젝트(`F:\UnrealProjects\KrakenVoyage`)의 실제 코드에서 가져온다. Grep/Read로 관련 파일을 찾아 실제 구현을 인용하고, `파일경로:줄번호` 출처를 남긴다. 지어내거나 일반화된 예시 코드를 쓰지 않는다.

## 노트 구조

```markdown
---
tags: [UE5, {세부태그}]
---

# {제목}

## 비유
{일상적 비유로 개념을 한두 문장 요약}

## 요약
| 항목 | 내용 |
|------|------|
| ... | ... |

## 코드 예시
\`\`\`cpp
// 출처: Source/KrakenVoyage/Private/{파일}:{줄번호}
{실제 프로젝트 코드}
\`\`\`

## 함정
- {흔한 실수나 이 프로젝트에서 실제로 겪은 문제}

## 연결
- [[관련개념1]]
- [[관련개념2]]
```

- 프론트매터의 `tags`는 최소 1개 이상, 관련 상위 개념 포함 (예: `Replication`, `RPC`, `Input`).
- `[[위키링크]]`로 관련 기존 노트를 연결한다. 연결 전에 볼트 내 기존 노트를 확인해 정확한 노트명을 쓴다 (없으면 만들 예정인 이름으로 링크만 남겨도 됨).
- Day별 노트는 그날 만든/수정한 개념·함정 노트들을 `[[위키링크]]`로 모아 나열하는 목차 성격.

## 어조

한국어로 작성. 인사말, 격려, 감탄사 없이 본론만. 설명체보다 정리체.

## 절차

1. 사용자가 지정한 학습 내용/커밋/코드 범위를 확인한다 (없으면 최근 대화나 최근 커밋에서 유추).
2. 관련 실제 코드를 Grep/Read로 찾는다.
3. 노트 유형(개념/함정/Day별)을 정하고 파일 경로를 정한다.
4. 볼트에 동일/유사 이름 노트가 있으면 덮어쓰기 전에 확인한다.
5. 위 구조로 마크다운을 작성해 볼트 경로에 저장한다.
